# Call AI

One giant **Live talk** button. Tap to open, tap to close. No login. Each visitor gets 5 minutes of talk time per day (tracked in the browser).

This repo is the front-end prototype: the button, the open/close states and the daily 5-minute timer. The live AI voice hookup is the next step and is not included, so the button shows the timer but doesn't talk yet.

Intended for hotels, senior living and sponsors who give guests a free, simple way to ask an AI anything.

- `index.html` – the whole app. Static, works on GitHub Pages.
